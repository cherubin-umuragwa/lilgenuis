## Directory Structure Created

```
src/
  app/                        # Next.js App Router (generated by create-next-app)
  components/
    layout/                   # Page layout wrappers (header, footer, shell)
    navigation/               # Nav bar, sidebar, breadcrumbs
    landing/                  # Landing page sections
    dashboard/                # Dashboard widgets and panels
    subjects/                 # Subject card, subject grid
    lessons/                  # Lesson viewer, step components
    quizzes/                  # Quiz UI components
    games/                    # Interactive game components
    achievements/             # Badge, trophy, celebration components
    characters/               # Mascot and character components
    shared/                   # Cross-feature reusable components
    ui/                       # Base UI primitives (button, card, modal…)
  features/
    learning/                 # Learning flow logic and state
    quizzes/                  # Quiz engine and scoring
    gamification/             # XP, levels, streaks, rewards
    progress/                 # Progress tracking and analytics
    onboarding/               # First-run and profile creation flow
    profile/                  # User profile management
  content/
    subjects/                 # Static subject metadata (TypeScript/JSON)
    lessons/                  # Lesson content files
    challenges/               # Challenge and activity content
    translations/             # i18n string files (en, fr, …)
  lib/
    data/                     # Data access helpers and loaders
    repositories/             # Repository layer (swap LocalStorage → Supabase later)
    storage/                  # LocalStorage abstraction utilities
    i18n/                     # i18n configuration and helpers
    utils/                    # General utility functions
  hooks/                      # Custom React hooks
  types/                      # Global TypeScript interfaces and types
  config/                     # App-wide constants and configuration

public/
  images/                     # General static images
  illustrations/              # Scene and decorative illustrations
  characters/                 # Mascot and character artwork
  icons/                      # SVG icon assets
```
